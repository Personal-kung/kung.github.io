To ensure your project evolves from a local prototype into a professional "Digital Ancestral Vessel" capable of global scaling and 10+ years of preservation, you must execute the following roadmap. These tasks are prioritized by their impact on architectural integrity and long-term data sovereignty.

---

## 1. **Foundational Security & Stability (Priority: CRITICAL)**
*   **Version Control Onboarding:** Export the **Virtual Notebook** code from Google AI Studio and initialize it as a private **GitHub repository**.
*   **The "Master System Manifest":** Document core logic, design tokens (hex codes), and API schemas to prevent "logic drift" in future AI-assisted coding sessions.
*   **Standardized Component Library:** Sync UI elements (parchment, typography, buttons) across the **Submission Tool**, **Curation Dashboard**, and **Virtual Notebook** to ensure a consistent "K-Level 5" aesthetic.
*   **Tools Required:** Git, GitHub, Markdown (for documentation).

---

## 2. **Resilience & Token Management (Priority: HIGH)**
*   **Queue-Based Processing:** Implement **Firebase Cloud Functions** with a message queue (e.g., Pub/Sub) to handle image and translation requests asynchronously.
*   **The "Circuit Breaker" Implementation:** Write fallback logic so the UI displays high-quality placeholders if APIs hit token limits or go offline.
*   **Distributed Caching Layer:** Configure **Redis** to store every generated image and translation permanently, ensuring zero-cost retrieval for repeated views.
*   **Tools Required:** Google Cloud Pub/Sub, Redis, Firebase Cloud Functions.

---

## 3. **Data Sovereignty & Preservation (Priority: HIGH)**
*   **Local/Cloud Hybrid Vault:** Establish an automated "Cron Job" to pull "raw" JSON/Markdown data from Firebase to local hardware every 24 hours.
*   **Immutable Backup Rule (3-2-1-1-0):** Ensure data exists in three locations, on two different media types, with one copy being physically offline (air-gapped).
*   **Future-Proof Formats:** Store author stories in **Markdown** or **JSON** alongside the AI-processed versions to ensure readability 50 years from now.
*   **Tools Required:** Synology NAS or Raspberry Pi (Local), Backblaze B2 (Offsite), Python/Node.js for sync scripts.

---

## 4. **Global Performance & Adaptability (Priority: MEDIUM)**
*   **The "Vessel State" Engine:** Implement a centralized state hook that switches the layout logic between **Mobile Leaf Mode**, **Desktop Two-Page Spread**, and **Projector Mode** (high-contrast).
*   **Edge Deployment:** Use **Cloudflare** or a Global CDN to cache approved stories at edge locations, ensuring sub-100ms loading times for readers worldwide.
*   **Automated Curation Triage:** Configure AI-driven pre-processing (Cloud Vision) to automatically tag and safety-check submissions before they reach your dashboard.
*   **Tools Required:** Cloudflare, CSS Container Queries, Tailwind CSS.

---

## 5. **Intelligent Evolution (Priority: STRATEGIC)**
*   **Semantic Search & Indexing:** Move beyond keyword searches to **Vector Embeddings**, allowing future readers to find stories based on "meaning" or "emotion."
*   **Agentic Maintenance:** Use frontier LLMs (e.g., Claude 4.5, GPT-5) as "Orchestration Agents" to monitor microservices and deploy autonomous fixes.
*   **Tools Required:** Pinecone/ChromaDB (Vector Database), LangGraph (Agentic Orchestration).
